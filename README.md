# Рабочие скрипты

## pubnuget.ps1 — сборка и публикация NuGet-пакетов

Скрипт собирает один или несколько проектов в конфигурации Release, упаковывает их в каталог `packages` и при необходимости публикует пакеты на nuget.org. Запускайте его из каталога, относительно которого заданы пути к проектам: там же будет создан каталог `packages`.

Нужны Windows PowerShell 5.1 или новее и .NET SDK.

```powershell
powershell -ExecutionPolicy Bypass -File .\pubnuget.ps1 [-Version] <версия> [-Project] <проект> [<проект> ...] [-Suffix <суффикс>] [-BuildOnly]
```

### Параметры

| Параметр | Обязательный | Описание |
| --- | --- | --- |
| `-Version` | да | Версия из трёх числовых частей, например `1.2.3`. |
| `-Project` | да | Путь к файлу проекта. Можно передать несколько путей. Абсолютный путь используется как есть, относительный считается от текущего каталога. |
| `-Suffix` | нет | Непустой суффикс версии пакета. Для версии `1.2.3` и суффикса `beta` версия пакета будет `1.2.3-beta`. |
| `-BuildOnly` | нет | Собрать и упаковать пакеты, но не публиковать их. |

`-Version` и `-Project` можно указывать позиционно, без имён параметров.

### Версии

Скрипт задаёт две версии:

- версия пакета — значение `-Version`, а при `-Suffix` ещё и суффикс;
- версия сборки и файла — значение `-Version` плюс текущие день и месяц в формате `ddMM`. Для 17 ноября и версии `1.2.3` это `1.2.3.1711`. Эти значения записываются в `AssemblyVersion` и `FileVersion`.

### Публикация

Без `-BuildOnly` скрипт читает ключ API из файла `%USERPROFILE%\.nuget\nuget.org.apikey`. Берётся первая непустая строка. Затем скрипт ждёт нажатия Enter и отправляет пакеты на `https://api.nuget.org/v3/index.json`. Пакет, который уже есть на сервере, пропускается.

Перед публикацией положите ключ в этот файл. Не храните ключ рядом со скриптом и не коммитьте его в репозиторий.

### Примеры

Собрать два проекта и опубликовать их:

```powershell
.\pubnuget.ps1 1.2.3 .\src\MyLib\MyLib.csproj .\src\MyLib.Tests\MyLib.Tests.csproj
```

Собрать предварительную версию, не отправляя пакет на сервер:

```powershell
.\pubnuget.ps1 -Version 1.2.3 -Project .\src\MyLib\MyLib.csproj -Suffix beta -BuildOnly
```

После успешной упаковки пакеты лежат в `.\packages`. При ошибке сборки, упаковки или публикации скрипт завершается с кодом 1.
